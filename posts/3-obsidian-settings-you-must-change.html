Obsidian Tutorial

3 Settings You MUST Change in Obsidian

TS
By Tech Simpld
•
Available Now
•
6 Min Read

Obsidian is hyped as the ultimate "second brain" tool, but let's be honest: your first 10 minutes with the app are usually awful. You download it, create a vault, and are greeted by a blank screen that doesn't behave like any normal word processor you've ever used. Formatting breaks, images dump into random places, and the famous Graph View looks like a tangled mess of useless dots.

I nearly uninstalled Obsidian on my first day. I just wanted to write a technical guide, but I spent 30 minutes fighting the editor's default behaviors.

The good news? You don't need to learn Markdown or CSS to fix this. In this guide, I'll walk you through the three core settings you must change immediately. These tweaks will force Obsidian to behave predictably, keep your file directory organized, and make the Graph View actually useful for finding data. Let's fix your vault.

Step 1: Fix Paragraph Spacing (Strict Line Breaks)

Because Obsidian relies on standard Markdown, it handles the "Enter" key differently than Google Docs. If you type a line, hit Enter once, and type a second line, it looks fine in Editing Mode. But the second you switch to Reading Mode, Obsidian smashes those two lines together into a single block of text. Standard Markdown requires you to hit Enter twice for a new paragraph.

This is incredibly frustrating when you're just trying to write a quick list or script. Nobody wants to retrain their muscle memory.

The Fix:

  • Click the gear icon (bottom left) to open Settings.
  • Click Editor in the left sidebar.
  • Scroll down and find Strict line breaks.
  • Toggle it Off.

Now, hitting Enter once actually creates a new line in Reading Mode. It instantly makes the editor feel like a normal word processor.

Step 2: Stop Image Clutter (Attachment Folder)

When you paste a screenshot into Apple Notes, it embeds seamlessly. In Obsidian, because everything is a local file, pasting an image creates an actual .png file inside your vault directory.

By default, Obsidian dumps every pasted image directly into your root folder. If you take visual notes, your sidebar will quickly become an unreadable garbage dump of files named Pasted image 20261012.png. Finding your actual markdown notes becomes impossible.

The Fix:

We need to force Obsidian to hide all media files in a dedicated background folder.

  • In your main file explorer sidebar, create a new folder and name it Attachments.
  • Open Settings and click Files and links.
  • Find the setting Default location for new attachments.
  • Change the dropdown from "Vault folder" to In the folder specified below.
  • In the box that appears, type Attachments and select the folder you just made.

Every screenshot, PDF, or audio file you paste will now be silently routed to that folder, keeping your root directory perfectly clean.

Step 3: Make the Graph View Usable

The Graph View is Obsidian's most marketed feature. But as your vault grows, the default settings turn it into a dense, unreadable ball of overlapping dots in the center of your screen. It looks cool, but it's functionally useless for actually navigating your knowledge base.

We need to apply forces to spread the nodes apart and add color-coding so you can instantly recognize topics.

The Fix:

  • Open the Graph View and click the gear icon in its top right corner to open the Graph settings.
  • Expand the Forces tab. Grab the Repulsion slider and drag it significantly to the right. This acts like a magnet, pushing notes away from each other and instantly untangling the massive clump.
  • Expand the Groups tab and click New group.
  • Type path:Projects (or whatever your folder is named) and select a bright color like Blue.
  • Create another group, type tag:#meeting, and select Green.

Your graph will expand into a clear, readable constellation, color-coded by context. You can now actually use it to spot orphaned notes or see how dense a specific project is getting.

Troubleshooting & Edge Cases

If things aren't working after making these tweaks, check these common pitfalls:

  • My Graph View is completely empty: The graph only connects notes if you actually create links. If you just type plain text and never use the [[Wikilink]] syntax, the graph will just be isolated, floating dots. You must link notes together to form connections.
  • Images are still going to the root folder: Double-check that you actually spelled your attachment folder correctly in the settings, and verify you didn't accidentally select "In subfolder under current folder" by mistake.
  • Reading mode still looks weird: If you're using a heavy custom CSS theme, it might override the Strict Line Breaks setting. Try reverting to the default Obsidian theme temporarily to isolate the issue.

Conclusion & Next Steps

Obsidian is a powerful engine, but it ships with terrible factory defaults. By turning off strict line breaks, routing attachments to a dedicated folder, and tuning the graph physics, you remove 90% of the friction for new users.

Your vault is now clean, predictable, and ready for actual work.
