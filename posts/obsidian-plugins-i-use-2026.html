3 Obsidian Plugins I Use in 2026

TS
By Tech Simpld
•
Available Now
•
8 Min Read

Out of the box, Obsidian is a blazing-fast plain text editor. If you're just writing grocery lists, that's fine. But when I tried to use it to manage complex YouTube production schedules, long-term project planning, and daily tasks, the plain text approach completely fell apart. Without customization, a growing vault turns into a chaotic, unsearchable mess of Markdown files.

The real power of Obsidian isn't the core app—it's the Community Plugins. These are third-party extensions that transform Obsidian from a basic notepad into a fully automated, visual project management system.

I've tested dozens of plugins, and 90% of them are unnecessary distractions. In this guide, I'll show you the three core plugins I rely on daily. We'll set them up in under 15 minutes to automate your workflow, visually organize your projects, and dynamically index your notes. No coding required.

Prerequisite: Enabling Community Plugins

Obsidian blocks third-party plugins by default for security. You have to opt-in.

  • Open Settings (gear icon bottom left).
  • Click Community plugins on the left sidebar.
  • Click Turn off Safe Mode.
  • Click the Browse button to access the plugin directory.

1. Kanban: Visual Project Management

If you've used Trello or Notion boards, you know how crucial visual task management is. Bullet point checklists are terrible for tracking projects that span multiple days.

The Kanban plugin (by mgmeyers) fixes this. It converts a plain Markdown note into an interactive, drag-and-drop board. I use this exclusively for my content calendar and video production pipelines.

Implementation:

  • Search for "Kanban" in the Community plugins browser. Install and Enable it.
  • Press Ctrl + P (or Cmd + P) to open the Command Palette.
  • Type Kanban: Create new board and hit Enter.

Add lists like To-Do, In Progress, and Completed. You can now visually drag tasks across stages. Because it's still Markdown under the hood, it remains lightning fast.

2. Dataview: The Database Engine

Dataview (by blacksmithgu) is the most powerful plugin in the ecosystem. It acts as a live query engine for your notes.

Before Dataview, if I wanted a list of every active project, I had to manually maintain an index note and constantly update links. With Dataview, I just tag my notes with #project, and write a query to pull them automatically.

Implementation:

  • Install and Enable "Dataview" from the plugin browser.
  • In any note, create a code block using three backticks and the word `dataview`. For example:
```dataview
LIST
FROM "Recipes"
```

The moment you click away, that block renders a live, clickable list of every file in your "Recipes" folder. If you add a new recipe tomorrow, the list updates instantly. It eliminates manual indexing entirely.

3. Templater: Workflow Automation

Obsidian's core template feature is weak. Templater (by SilentVoid13) is a massive upgrade because it executes dynamic commands when a template is inserted.

I use Templater to generate my daily logs. Instead of manually typing today's date and formatting the headers every morning, Templater does it for me the second I trigger it.

Implementation:

  • Install and Enable "Templater".
  • Create a folder in your vault called Templates.
  • Go to Settings > Templater. Set the Template folder location to your new Templates folder.
  • Create a new note in that folder called "Daily Log" and paste this code:
# Daily Log: <% tp.date.now("YYYY-MM-DD") %>

## Focus Tasks
- [ ] 

## Notes

When you insert this template, <% tp.date.now("YYYY-MM-DD") %> is automatically replaced with the actual current date. You never have to type dates manually again.

Troubleshooting & Edge Cases

Here are the most common issues you'll run into when setting these up:

  • Dataview tables are empty: Check your syntax. Dataview tags are case-sensitive. #Project will not match a query looking for #project. Also, ensure you haven't put spaces in your YAML frontmatter keys.
  • Templater tags aren't resolving: If you see the raw <% %> code instead of a date, you likely used Obsidian's default "Insert template" command. You must use the Templater: Open Insert Template modal command (Alt+N by default) for the scripts to execute.
  • Vault performance is lagging: While these three plugins are highly optimized, installing 40 other random plugins will cripple Obsidian's speed. Only install what you actively use.

Conclusion & Next Steps

These three tools—Kanban, Dataview, and Templater—are the holy trinity of a functional Obsidian workflow. They automate the boring stuff, provide visual clarity, and turn a static text editor into a dynamic database. Stop endlessly configuring settings and start building your actual knowledge base.
