Alexandrie Hub: A Gorgeous Self-Hosted Note-Taking Knowledge Base Alternative

TS
By Tech Simpld
•
Available Now
•
9 Min Read

If you hang around the self-hosting community long enough, you'll eventually realize that finding the "perfect" note-taking system is a never-ending obsession.

For years, I bounced between extremes. Cloud apps like Notion look great but force you to surrender your data to a third party. Local-first apps like Obsidian are incredibly powerful and secure, but syncing them across locked-down work laptops and mobile devices requires custom sync servers or iCloud workarounds.

I needed something in the middle: a self-hosted, web-first Markdown engine that I fully control. That's when I deployed Alexandrie Hub.

In this guide, I'll show you exactly why Alexandrie Hub is rapidly becoming my favorite web-based knowledge base, how it stacks up against Obsidian, and how you can deploy it in your home lab in under five minutes.

Why Alexandrie Hub? (The Core Features)

Alexandrie Hub is a lightweight, open-source web application designed specifically for personal knowledge management (PKM). It drops the bloated PHP runtimes of traditional wikis like BookStack and focuses on speed, Markdown, and visual design.

Here are the features that actually matter when you deploy it:

1. Native Web-First Architecture

This is the killer feature. Because it's a web service running on a Docker container in my Proxmox lab, I don't need a desktop client. I open Chrome on my work laptop, type in my local IP, and my entire knowledge base is instantly there. No syncing conflicts, no iCloud delays.

2. Flawless Markdown Editing

I write exclusively in Markdown. Alexandrie offers a distraction-free, real-time editor that renders headers, code blocks, and bullet points instantly without requiring a page refresh.

3. Built-In Graph Visualization

Obsidian made the "Graph View" famous—a visual web showing how all your notes connect to each other. Alexandrie Hub brings this directly into the web browser. It's built-in natively, requiring zero plugin configuration.

4. Mermaid Diagram Support

As a home labber, I draw a lot of network diagrams. Alexandrie supports Mermaid syntax out of the box, letting me generate flowcharts using pure text.

Deployment: The Docker Compose Setup

Deploying this is trivial. Here is the exact docker-compose.yml I use to spin it up: 

services:
  alexandrie:
    image: ghcr.io/smaug6739/alexandrie:latest
    container_name: alexandrie_hub
    restart: unless-stopped
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
      - PORT=3000
    volumes:
      - ./alexandrie-data:/app/data

Run docker compose up -d, navigate to port 3000, and you're in.

Troubleshooting & Edge Cases

If you're deploying this in a lab, keep these things in mind:

  • Data Portability: Unlike Obsidian, Alexandrie stores your notes inside a database, not as raw .md files on your file system. If you want to migrate away later, you must rely on the application's export tools. Ensure you are backing up the entire /app/data volume.
  • Reverse Proxy Issues: If you are placing Alexandrie behind Nginx Proxy Manager or Cloudflare Tunnels, ensure you are passing WebSocket connections. The real-time editor and graph views rely on WebSockets, and failing to pass them will result in constant disconnect errors.

Conclusion & Next Steps

If you require thousands of custom plugins and raw local files, stick with Obsidian. But if you want a beautiful, zero-configuration Markdown knowledge base that you can access instantly from any browser in the world, Alexandrie Hub is phenomenal. It strikes the perfect balance between design and self-hosted control.
