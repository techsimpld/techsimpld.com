Put Claude in Obsidian: Pay-As-You-Go AI Note Assistant Setup

TS
By Tech Simpld
-
September 2026
-
15 Min Read

Most people using artificial intelligence to assist their personal knowledge management workflow do it the hard way. They write rough notes in Obsidian, copy chunks of text into a browser tab running Claude or ChatGPT, wait for an answer, and then copy and paste the formatted response back into their vault.

Beyond being tedious, many creators and researchers pay a flat $20 monthly subscription fee just to ask a handful of questions or generate occasional summaries. If you only interact with AI models a few times a week, you are paying an exorbitant markup for capacity you never use.

In this guide, we are eliminating that friction entirely. By purchasing inexpensive pay-as-you-go developer credits directly from Anthropic, generating an API key, and connecting it to Obsidian using the open-source Copilot community plugin, Claude lives directly inside your markdown notes. You pay only fractions of a cent per request, and the assistant can directly read, organize, link, and create notes right inside your vault.

Web Subscriptions vs. Direct API Tokens: The Math

Understanding the distinction between consumer web chat subscriptions and developer platform APIs is the key to massive cost savings:

  • Claude Pro / ChatGPT Plus: A flat $20 every 30 days regardless of whether you send 10 prompts or 1,000 prompts. You are restricted to a web browser window and forced to manually shuffle text back and forth.
  • Anthropic Developer API (Pay-As-You-Go): You purchase a $5 prepaid credit balance. Tokens are billed strictly by volume (input tokens sent, output tokens received). Using cost-efficient models like Claude 3.5 Haiku, a typical note summary costs roughly $0.002 to $0.04. That initial $5 balance can comfortably last casual to moderate note-takers several months.

Core Capabilities of an Embedded Vault Agent

When Claude operates through an embedded plugin rather than an isolated browser tab, it gains contextual awareness of your workspace. Key practical use cases include:

  1. Active Note Refactoring: Highlighting a messy bulleted meeting transcript and asking Claude to restructure it into action items, decisions, and clear headings directly inside the active document.
  2. Automated Split Notes & Indexing: Taking a long, unstructured research note (e.g., character profiles and world lore) and commanding the model to split the content into individual atomic notes while automatically updating the primary note into an index with clickable [[Wikilinks]].
  3. Multimodal Homelab Documentation: Feeding a photograph of your server rack, networking switch, or Proxmox dashboard to Claude 3.5 Sonnet to automatically generate structured hardware specifications and configuration markdown tables.
  4. Autonomous Project Scaffolding: Granting the agent permission to create subfolders, legal documents, deployment checklists, and project matrices from a single prompt in minutes.

Step 1: Setting Up the Anthropic Developer Console

To obtain an API key, we connect to the official Anthropic Developer Platform:

  1. Navigate to the Anthropic Developer Console.
  2. Create or sign into your developer account. Notice that this is separate from a standard consumer Claude web subscription.
  3. Under the Billing section, add prepaid credits. The minimum initial funding deposit is $5.00. This is plenty of credit to get started.
  4. Navigate to the API Keys tab in the console sidebar.
  5. Click Create Key in the top right corner.
  6. Give your key a recognizable identifier, such as Obsidian Copilot.
  7. Select your preferred expiration window (such as 30 days or custom duration) and generate the token string.
  8. Copy the generated key immediately and leave the tab open temporarily. Anthropic will not display the key string again once you navigate away.

Step 2: Installing the Copilot Community Plugin

With your developer credentials ready, open your primary Obsidian vault:

  1. Click the Settings gear icon in the lower-left corner of Obsidian.
  2. Select Community plugins from the options sidebar and make sure Restricted Mode is turned off.
  3. Click Browse, search for Copilot (developed by Logan Yang), and click Install, followed by Enable.
  4. Close the plugin marketplace window and scroll down to the bottom of the main settings panel to find Copilot under Community Plugins.

Step 3: Configuring the Anthropic API Provider

In the Copilot settings panel, we configure the connection to Anthropic:

  1. Locate the BYOK (Bring Your Own Key) section at the top of the plugin configuration.
  2. Click Add Provider and select Anthropic from the provider list.
  3. Paste your copied API key into the API Key field.
  4. Click the Test / Verify button. The status badge will switch to verified, confirming a successful handshake between your local Obsidian client and Anthropic servers.
  5. Under the default model selector, choose your preferred model:
    • Claude 3.5 Haiku: Recommended for daily drafting, grammar cleanup, task extraction, and note summaries. It operates at blazing speed and costs fractions of a cent per execution.
    • Claude 3.5 Sonnet: Select this when you require deep analytical reasoning, complex code generation, or multimodal image analysis (inspecting rack photos, diagrams, or architecture screenshots).
  6. Save your settings and exit the menu.

Step 4: Launching the Vault Agent & Execution Modes

Look at the left icon ribbon inside Obsidian. You will notice a new icon labeled Open Copilot Agent Chat.

Clicking this icon opens a dedicated chat panel in your right sidebar. If prompted on initial launch to download a binary engine (such as OpenCode), click Download and Install. In the model dropdown at the top of the chat panel, confirm that your Anthropic Claude model is highlighted.

The plugin offers two distinct execution modes:

  • Supervised Mode (Default): Every time the AI proposes modifying a note, appending text, or creating a new document, Obsidian prompts you with an explicit confirmation dialog: Allow Once or Always Allow. This ensures you maintain full editorial control over your vault files.
  • Autonomous Mode (Auto): When toggled to Auto (indicated by a red indicator box), the agent executes multi-step workflows independently without stopping to ask permission for every single markdown modification or folder creation. Use this mode for rapid project scaffolding.

Real-World Walkthrough 1: Restructuring Messy Research Notes

To test the assistant, open an unorganized note with raw bullet points or disjointed brainstorms. In the Copilot chat window, issue a direct prompt: 

Please review my active note. Restructure the messy notes into clear logical sections, fix typos, and preserve all key details.

Claude reads the active buffer, organizes the content into clear subheadings, and prompts you to review the proposed diff. Accepting the change rewrites the note into a clean, scannable document. Checking your Anthropic console reveals a total consumption of approximately $0.04.

Real-World Walkthrough 2: Splitting Atomic Notes with Backlinks

Obsidian functions best when ideas are split into atomic notes linked via Wikilinks. You can instruct Claude to handle this entire refactor: 

Break out the active note into separate atomic notes for each main character and each location. Then update the original note into an index note containing direct Wikilinks to each newly created page.

The agent creates individual markdown files in your vault (e.g., Characters.md, Locations.md) and replaces the monolithic text in your root note with clean links: 

# Project Master Index

## Quick Links
- [[Characters]] - Comprehensive roster and affiliations
- [[Locations]] - Regional mapping and infrastructure

Real-World Walkthrough 3: Multimodal Homelab Audits with Sonnet

If you switch your model to Claude 3.5 Sonnet, you can leverage computer vision directly inside your vault.

Paste a screenshot of your physical home server rack or your Proxmox node overview directly into the chat prompt with the following command: 

Inspect this photo of my homelab server cluster. Document the visible physical nodes, enumerate shared specs, and format the output into a clean hardware reference table in my vault.

Within roughly 20 seconds, Sonnet examines the image, identifies the hardware enclosures, and outputs a complete, formatted hardware inventory note that integrates into your technical documentation vault.

Security and Data Privacy Best Practices

While pay-as-you-go API integration provides exceptional productivity, keep these privacy considerations in mind:

  • Commercial Data Protections: According to Anthropic's developer commercial terms of service, inputs and outputs processed through paid developer API keys are not used to train foundation models, offering significantly greater confidentiality than free consumer web tiers.
  • Sensitive Data Quarantine: If your vault contains highly classified credentials, private keys, or personal health records, configure Copilot's ignore rules or refrain from feeding those specific directories into the prompt context.
  • Set Spend Caps: Inside the Anthropic Developer Console, configure monthly spend limits (e.g., $10 maximum) to prevent accidental runaway API bills during automated scripting loops.

Summary and Next Steps

By integrating Claude directly into Obsidian via the Copilot plugin, you eliminate the tedious copy-paste loop and liberate your budget from expensive monthly recurring subscriptions. You gain an context-aware, context-aware second brain assistant that costs only pennies when you need it and nothing when you don't.
